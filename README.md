# 词面覆盖台 lexical-cover

纯前端单文件工具：填「已认识词表」+ 一段分行台词，逐句算词次覆盖与「能听懂」标记，再枚举全部 2^U 个补词子集，给出达到目标所需**精确最少词集**，并与预算内最优、频次 top-k、贪心三条路线对照。

- 构建：`node build.cjs`（把 `core.js` / `ui.js` 内联进 `template.html` → `index.html`）
- 测试：`node --test tests/core.test.cjs`
- 打开 `index.html` 即可用，无需服务器、无需模型 API、不联网、不上传输入。
- 默认数据、封面与导出数字均为虚构示例；不查词典、不预测真实听力或词汇量。
